# BOOK

A PERSISTENT-STRUCT (and so, transitively, a PERSISTENT-OBJECT, GIT-TREE, and STANDARD-OBJECT) generated by DEFINE-PERSISTENT-STRUCT, with one slot per name in (ISBN
                                                                                                                                                                 TITLE
                                                                                                                                                                 AUTHOR
                                                                                                                                                                 CHECKED-OUT-P). See MAKE-BOOK and BOOK-P.

## Slots

  * **isbn**: The ISBN slot of a BOOK instance.
  * **title**: The TITLE slot of a BOOK instance.
  * **author**: The AUTHOR slot of a BOOK instance.
  * **checked-out-p**: The CHECKED-OUT-P slot of a BOOK instance.
