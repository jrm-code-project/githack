# PERSISTENT-HASH-TABLE

A PERSISTENT-STRUCT (and so, transitively, a PERSISTENT-OBJECT, GIT-TREE, and STANDARD-OBJECT) generated by DEFINE-PERSISTENT-STRUCT, with one slot per name in (TEST
                                                                                                                                                                 COUNT
                                                                                                                                                                 BUCKETS). See MAKE-PERSISTENT-HASH-TABLE and PERSISTENT-HASH-TABLE-P.

## Slots

  * **test**: The TEST slot of a PERSISTENT-HASH-TABLE instance.
  * **count**: The COUNT slot of a PERSISTENT-HASH-TABLE instance.
  * **buckets**: The BUCKETS slot of a PERSISTENT-HASH-TABLE instance.
